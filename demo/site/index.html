Before you start

This page is served from 127.0.0.1, so it is treated as a local address — the extension never sends local pages for reputation checks. The stations below still work because they rely on the on-device engine, the ad rules and Download Guard.

Load the extension, then open its options and turn on everything you want to show:

  • Credential Guard — for station 3 (needs one-time site-access permission).
  • Block ads and trackers + Hide empty ad spaces — for station 1.
  • Download Guard — on by default, for station 4.
  • Keep the API server running (npm run dev:server) for the file / QR / password / link checks in station 6.

Tip: after you change an ad or guard setting, use the extension popup's Reload this page to apply button — network rules only affect requests made after they change.

2Checkout — scan to "get your refund"

Classic UPI trap: you are told to scan a QR to receive a refund, but a pay-QR can only send money. Scan the left QR with the extension and it explains exactly what the code does.

"Scan to receive your ₹4,999 cashback refund." This is the scam.
An ordinary merchant QR, for contrast. No alarm.
  • Open the extension → Security Center → Scan QR.
  • Upload demo/qr/upi-refund-scam.png (or screenshot this screen).
  • Expected: likely phishing — "Says you will receive money, but this QR takes money."

Watch for: the plain-language line that scanning and entering your UPI PIN would send ₹4,999, not receive it, and the "report at cybercrime.gov.in / 1930" advice.

4Dangerous downloads — Download Guard

These are the kinds of files sent over WhatsApp and email. They are harmless demo files (no runnable code), but they carry the lure names and types real scams use. Download Guard pauses the risky ones and asks first.

SBI_YONO_KYC_Update.apk Salary_Revision_2026.docm Secure_Message_HDFC.html Electricity_Bill_Disconnection.pdf My_Notes.txt (safe)

Watch for: the APK download pauses partway (it is served slowly on purpose) and the guard page opens. Click Cancel download — the file is removed, even if it had finished. The plain .txt is allowed through without a prompt.

5Phishing links — full-page warning

These links use real lookalike tricks. They point to domains that do not exist, so nothing loads — the warning appears before the page, from the on-device check alone.

  • sbi.co.in.secure-login.click/kyc — the real domain is secure-login.click, not SBI.
  • paypa1.com/signin — "paypa1" with a digit one.
  • hdfcbank-kyc-update.in/login — a brand name stitched into a new domain.
  • onlinesbi.sbi — the genuine SBI site, for contrast (no warning).

Watch for: the orange / red full-page warning listing the evidence, the "Listen in Hindi" button, and the toolbar badge. The real SBI link loads normally.

6Scan anything yourself

The Security Center and popup let you check things on demand.

  • Scan a link: popup → paste any URL → see the verdict and evidence.
  • Scan a file: Security Center → add a file from demo/files/. The APK reads as ~97; the HTML attachment ~75.
  • Password check: Security Center → type password — it is found tens of millions of times, and only the first 5 characters of its hash ever leave your device.

Watch for: every verdict shows why, and never claims a site is "safe" — only "no known threats".

Remember: this is a training range. If you ever hit a real scam — a QR, a call, a fake site — stop and report it.
